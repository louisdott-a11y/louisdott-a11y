## Projects

### [Clearline SAT](https://github.com/louisdott-a11y/clearline-sat) · [live site](https://clearline-sat.pages.dev)
Free SAT prep where every answer is checked and every wrong choice is explained. It has adaptive mock tests, Desmos calculator lessons, analytics, vocab games and a mistakes notebook. I came up with the idea, researched what the best SAT prep sites do well, chose every feature, directed the design, tested it on real devices, and shipped it. Plain HTML, CSS and JavaScript, hosted on Cloudflare Pages.
